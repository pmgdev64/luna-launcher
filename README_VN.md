# Luna Launcher

Một launcher Minecraft nhẹ, mã nguồn rõ ràng và an toàn.

---

## 🚀 Giới thiệu

- **Lightweight và dễ dùng**  
- **Mã nguồn sạch** — không có Win32 API binding, không có mã ẩn, không chứa malware  
- **Open-source** (bản Free) — bạn có thể tự build, kiểm tra  
- **Premium version** sẽ có bản quyền và mã nguồn đóng, với các tính năng cao cấp  

---

## ⚙️ Tính năng (Features)

### Bản Free / Community

- Đăng nhập, tải game, quản lý phiên bản  
- Cập nhật nhanh, giao diện đơn giản  
- Minh bạch, không chứa code ẩn  
- Tương thích đa nền tảng (Windows, macOS, Linux) — nếu bạn hỗ trợ  

### Bản Premium (sắp tới)

- Theme / giao diện tuỳ chỉnh  
- Quản lý mod / plugin chuyên sâu  
- Lưu trữ đám mây / đồng bộ  
- Support / cập nhật ưu tiên

---
