# Luna Launcher – Beta 0.0.03

**Chủ đề:** `earlyWinter`  
**Ngày phát hành:** 26/10/2025  
**Tác giả:** PmgDev64 / PepperMCGamers Ch. PmgTeam  

Trình khởi chạy Minecraft nhẹ, sạch, hiện đại với giao diện phong cách anime học viện.

---

## 🚀 Giới thiệu

- **Nhẹ và dễ sử dụng** – tối ưu cho mọi máy tính.  
- **Mã nguồn sạch** — không dùng Win32 API, không ẩn code, không malware.  
- **Mở nguồn (bản miễn phí)** — build và test tự động.  
- **Bản beta** — thử nghiệm các hiệu ứng mới, overlay mùa đông.  
- **Bản premium (sắp ra)** — thêm theme, quản lý plugin, đồng bộ cloud.

> ⚠️ Đây là **bản beta**. Có thể gặp lỗi hoặc thiếu tính năng. Sao lưu dữ liệu trước khi dùng.

---

## ⚙️ Tính năng

### Bản miễn phí / cộng đồng

- Login, download games, quản lý phiên bản  
- Cập nhật nhanh, giao diện đơn giản  
- Minh bạch, không ẩn code  
- Hỗ trợ đa nền tảng (Windows, macOS, Linux) — nếu có  

### Tính năng riêng của beta (0.0.03)

- Overlay mùa đông `earlyWinter`  
- Hệ thống UI Pack mới  
- Một số hiệu ứng GUI thử nghiệm và cải tiến  

### Bản premium (sắp ra)

- Theme/skin tùy chỉnh  
- Quản lý mod/plugin nâng cao  
- Lưu trữ/đồng bộ cloud  
- Hỗ trợ và cập nhật ưu tiên
