## 🚀 Introduction

Luna Launcher là một trình khởi chạy Minecraft hiện đại, ưu tiên sự mượt mà và giao diện tối giản. Đây là bản phát hành chính thức đầu tiên (Global) tập trung vào việc xây dựng nền tảng vững chắc cho hệ thống module sau này.

---

## 🆕 What's New in v0.0.1

### ✨ Key Features & Logic
* **Anime-Inspired UI:** Giao diện hiện đại, tối giản và mang phong cách anime.
* **Smart Configuration (Auto-Save):** * Mọi thiết lập khi bạn toggle (bật/tắt) các module sẽ được **tự động lưu (autoSave)** ngay lập tức.
    * Đảm bảo trạng thái launcher luôn được bảo toàn mà không cần nút "Lưu" thủ công.
* **New Year Theme:** Giao diện đặc biệt `NewYearCelebration` dành riêng cho dịp ra mắt đầu năm 2026.

### 🛠️ Technical Improvements
* **Fixed Critical Bugs:** Sửa lỗi crash JVM khi khởi chạy Minecraft 1.14 trở lên.
* **New Installation Path:** Chuyển đường dẫn mặc định sang `C:\Users\<Username>\lunaLauncher` để tránh lỗi quyền ghi file (Permission handling).
* **Architecture:** Tái cấu trúc Core để tách biệt rõ ràng giữa các module tính năng và bộ máy khởi chạy.

### 🔐 Systems Under Development (Inactive)
* Đã tích hợp framework cho **AuthAPI** và **Payment System** (Hiện tại đang ở trạng thái placeholder, sẽ được kích hoạt trong các bản cập nhật tới).

## 📦 Distribution Information

* **Installer:** Được đóng gói bằng **NSIS**, hỗ trợ wizard cài đặt chuyên nghiệp và trình gỡ cài đặt (Uninstaller) sạch sẽ.
* **Wrapper:** Sử dụng **Launch4j** để đóng gói Java wrapper thành file thực thi (.exe) trên Windows.
* **Note:** Bản release này chưa sử dụng `jpackage`.
