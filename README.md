## ✨ About

Luna Launcher is an indie Minecraft launcher project focused on providing a **simple, lightweight, and modern launcher experience**.

The launcher combines a clean interface with an anime-inspired visual style while keeping the application focused on the essentials.

The project is being redesigned in C++ to improve performance, reduce runtime dependencies, and provide greater control over the launcher architecture.

---

## 🚀 Project Direction

### Legacy Version

The original Luna Launcher was developed using:

* Java
* JavaFX 17
* Windows

This version represents the first official release of the project.

### C++ Rewrite

The upcoming version will be rebuilt using **C++**.

The rewrite is intended to provide:

* ⚡ Lower runtime overhead
* 🚀 Faster startup
* 🧩 Better control over dependencies
* 💾 Lower memory usage
* 🔧 Easier integration with native Windows APIs
* 🔐 A more controlled installation and update system
* 📦 A redesigned launcher architecture

The C++ rewrite is a **new generation of Luna Launcher**, rather than simply a Java-to-C++ source conversion.
