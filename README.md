# Luna Launcher

A lightweight, clean and secure Minecraft launcher.

---

## 🚀 Introduction

- **Lightweight and easy to use**
- **Clean source code** — no Win32 API bindings, no hidden code, no malware
- **Open-source** (free version) — you can build, test automatically
- **Premium version** will have copyright and source code with premium features

---

## ⚙️ Features (Features)

### Free / Community version

- Login, download games, version management
- Fast updates, simple interface
- Transparent, no hidden code
- Similar cross-platform (Windows, macOS, Linux) — if you support

### Premium version (coming soon)

- Custom themes/skins
- In-depth mod/plugin management
- Cloud storage/sync
- Priority support/updates
